# 科技投资观察台

[打开面板](https://semiconductor-brief-cn.github.io/)

工作台包含新闻时间线、财经日历、日／周／月简报、事件追踪、标的观察和决策复盘。时间按香港时区显示。自定义观察标的、事件和决策记录只保存在当前浏览器。

GitHub Actions 每 5 分钟尝试读取英伟达、AMD、美联储和美国经济分析局的公开订阅，以及美国劳工统计局和美国经济分析局的官方日历。定时启动及数据到达可能延迟。看板每 30 秒检查 GitHub 上的公开快照。部分来源失败时保留其上次成功读取的记录。公司财报与听证等手动核对的日程、已有 X 原帖仍可查看。新增观察标的会匹配已采集的数据，采集范围由公开订阅决定。

可用 `python3 update_feed.py feed.json` 更新随站发布的公开快照。
